Do NOT commit mainnet validation keys into the repository. The mainnet
validation key must be published to your production host at the path
/validation-key.txt so the CiDi Games platform can validate the app.

To publish the validation key to your production host (Lovable):

1. In your Lovable dashboard, add a static file named `validation-key.txt` with
   the exact content provided by the platform.
2. Ensure the file is served at: https://<your-production-domain>/validation-key.txt
3. Do NOT store the key in Git. After publishing, you may rotate the key and
   remove any copies stored elsewhere.

This placeholder replaces the previous committed key to avoid leaking
sensitive data in source control. If you need assistance publishing, use
Lovable's static file upload in the Storage or Files section.
